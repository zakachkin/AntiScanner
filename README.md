# AntiScanner (форк с ipset hash)

**AntiScanner** — это форк оригинального скрипта, адаптированный для работы с `ipset` на основе хеш-наборов (тип `hash`).

## Что изменено и для чего нужен ipset hash

В этом форке вместо классического `iptables`-списка используется `ipset` с типом `hash` (например, `hash:ip` или `hash:net`):

- адреса и подсети складываются в ipset-набор;
- `iptables` обращается не к длинному списку правил, а к одному набору;
- операции добавления/удаления IP выполняются быстрее и не нагружают таблицы.

Зачем это нужно:

- эффективная блокировка большого количества IP или сетей (сканеры, ботоводы, агрессивные сети);
- более высокая производительность по сравнению с добавлением множества отдельных правил в `iptables`;
- удобнее динамически обновлять списки (бан по логам, автодобавление сканеров и т.п.).

## Назначение

Скрипт предназначен для защиты VPS или другого сервера от:

- массового сканирования портов;
- автоматизированных атак;
- агрессивного/подозрительного трафика с большого числа IP.
